## 1. Prerequisites
- A **GitHub Account** ([github.com](https://github.com)).
- A **Hostinger Account** with an active domain and hosting plan (Web Hosting, Cloud Hosting, or VPS).
- Git installed on your local computer.

---

## Step 1: Push Project to GitHub

1. Create a new repository on GitHub (e.g. `purenest-cleaning`). Leave it empty (no initial README or license).
2. On your computer, open your terminal inside the project directory:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of PureNest Cleaning Co. website"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/purenest-cleaning.git
   git push -u origin main
   ```

## Method A: GitHub Actions (Recommended — Automatic Build & Deploy)

This project already includes `.github/workflows/deploy.yml`. Whenever you run `git push origin main`, GitHub will automatically build your website and upload it to Hostinger's `public_html` directory.

### 1. Get Your Hostinger FTP Credentials
1. Log in to your **Hostinger hPanel**.
2. Go to **Websites** → click **Manage** on your domain.
3. In the search bar on the left, type **FTP Accounts** and select it.
4. Note down:
   - **FTP IP / Hostname** (e.g. `ftp.yourdomain.com` or an IP address).
   - **FTP Username** (e.g. `u123456789`).
   - **FTP Password** (click *Change Password* if you do not remember it).
   - **Port** (usually `21`).

### 2. Add Secrets to GitHub
1. In your GitHub repository, click **Settings** (top navigation).
2. In the left sidebar, click **Secrets and variables** → **Actions**.
3. Click **New repository secret** and add the following 3 secrets:
   - Name: `FTP_SERVER` → Value: Your Hostinger FTP Host (e.g., `ftp.yourdomain.com`)
   - Name: `FTP_USERNAME` → Value: Your Hostinger FTP username
   - Name: `FTP_PASSWORD` → Value: Your Hostinger FTP password

### 3. Trigger Deployment
1. Make any edit or push a commit:
   ```bash
   git commit --allow-empty -m "Trigger Hostinger deployment"
   git push origin main
   ```
2. Go to the **Actions** tab in your GitHub repository.
3. You will see the **Deploy to Hostinger** workflow run:
   - Check out code
   - Install dependencies
   - Build production assets into `dist/`
   - Upload via FTP directly into Hostinger's `public_html`
4. Once it turns green, visit `https://yourdomain.com`!

## Method B: Hostinger Git Tool in hPanel

If you prefer Hostinger to pull the repository directly:

1. Open your **Hostinger hPanel** → **Manage Website**.
2. Search for **Git** in the left menu.
3. In the Git deployment screen:
   - **Repository**: `https://github.com/<YOUR-USERNAME>/purenest-cleaning.git`
   - **Branch**: `main`
   - **Install directory**: Leave empty or set to `/`
4. If your GitHub repository is private:
   - Copy the **Deploy Key** generated by Hostinger.
   - In GitHub, go to your repository → **Settings** → **Deploy keys** → **Add deploy key** and paste it.
5. In Hostinger, click **Create**.
6. Set up the **Auto Deployment Webhook**:
   - Hostinger provides a Webhook URL.
   - Go to your GitHub repository → **Settings** → **Webhooks** → **Add webhook**.
   - Paste the Hostinger URL in **Payload URL**, set content type to `application/json`, and save.
   - Whenever you push code to GitHub, Hostinger will automatically pull the latest changes.

> **Note on Build**: If using Hostinger Shared Hosting's Git tool directly, ensure either your CI builds into a release branch, or push the pre-built `dist/` folder, or use Method A (GitHub Actions), which handles the build step automatically.

## Method C: Hostinger VPS / Node.js Hosting

If you are using Hostinger VPS or a plan that supports Node.js daemons and you want the Express backend server (`server.ts`) running continuously:

1. Connect to your VPS via SSH:
   ```bash
   ssh root@your-vps-ip
   ```
2. Clone your GitHub repository:
   ```bash
   cd /var/www
   git clone https://github.com/<YOUR-USERNAME>/purenest-cleaning.git
   cd purenest-cleaning
   ```
3. Install dependencies and build:
   ```bash
   npm install
   npm run build
   ```
4. Start the server using PM2 (process manager):
   ```bash
   npm install -g pm2
   pm2 start "npm start" --name "purenest"
   pm2 save
   pm2 startup
   ```
5. Configure Nginx reverse proxy to forward requests on port 80/443 to `http://localhost:3000`.

## Post-Deployment Checklist

- [ ] **SSL Certificate**: In Hostinger hPanel, enable **Free Lifetime SSL** under *Security*.
- [ ] **Clean URLs**: Verify that clicking between *Home*, *Services*, *About Us*, and *Contact Us* works smoothly. The included `.htaccess` automatically routes all requests to `index.html`.
